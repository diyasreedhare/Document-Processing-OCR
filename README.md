# Document Processing and Data Extraction using OCR & Computer Vision

## Project Overview
This project focuses on extracting text from images and scanned documents using Optical Character Recognition (OCR) and computer vision techniques. It uses Python libraries to process documents and make text extraction easier.

## Technologies Used
- Python
- OpenCV
- EasyOCR
- Pandas
- NumPy

## Features
- Extract text from images using OCR.
- Process images using computer vision techniques.
- Handle extracted text using Python.
- Support document data processing.

## Installation

1. Clone the repository:

   `git clone https://github.com/diyasreedhare/Document-Processing-OCR.git`

2. Open the project folder:

   `cd Document-Processing-OCR`

3. Install the required libraries:

   `pip install -r requirements.txt`

## How to Run

Run the following command:

`python ocr_project2.py`

## Project Structure

- `ocr_project2.py` – Main Python program.
- `requirements.txt` – Required Python libraries.
- `README.md` – Project documentation.
